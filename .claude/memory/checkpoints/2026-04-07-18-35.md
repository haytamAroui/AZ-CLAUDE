## What I'm doing right now

## Why — key decisions made this session

- **Knowledge layer architecture**: inspired by Karpathy's LLM Wiki pattern and MirkoSon/llm-wiki-vault. AZCLAUDE's version is active (agents consume knowledge) vs wiki-vault's passive (human reads wiki). Key differentiator: `code_refs` field creates bidirectional code↔knowledge tracking.
- **2 new commands, 1 new agent**: /ingest (process docs → knowledge pages), /knowledge (status/query/health-check), knowledge-compiler (sonnet model — extraction complexity justified the cost over haiku).
- **Knowledge generation is passive**: /fix, /debate, /explain, /persist all offer to file knowledge as a side effect of normal work. No separate workflow needed.
- **Constitutional validation of ingested knowledge**: constitution-guard checks new knowledge against non-negotiables at ingest time — prevents knowledge pollution.
- **Cycle 4 in /evolve**: staleness detection via code_refs, orphan detection, gap detection, confidence decay, contradiction scan — auto-healing knowledge base.
- **code-reviewer, constitution-guard, milestone-builder all upgraded**: knowledge-layer Integration Rules were one-way promises until agents were wired — code-reviewer found this in review.
- **DOCS.md counts updated**: 42→44 commands, 15→16 agents across all 6 required doc files per Release Process.
- **Version bumped to 0.8.0**: minor bump because knowledge layer is a significant new capability, not just a patch.
