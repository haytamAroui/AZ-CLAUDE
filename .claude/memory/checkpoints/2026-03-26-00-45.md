## What was done this session

### v0.5.0 published to npm — 6 major features

1. **Statusline** — auto-installing context %, rate limit, cost bar in ~/.claude/statusline.sh
   - Color-coded thresholds (green/yellow/red), jq fallback, session time, lines changed
   - Installer wires into ~/.claude/settings.json automatically

2. **Agent Auto-Dispatch** — 10 agent triggers added to CLAUDE.md template
   - problem-architect, code-reviewer, test-writer, orchestrator, security-auditor,
     architecture-advisor, devops-engineer, qa-engineer, spec-reviewer, constitution-guard

3. **Brain Router** — hook-enforced mandatory pipeline on EVERY message
   - UserPromptSubmit hook now fires on every message (not just session start)
   - Detects intent: BUILD, FIX, REVIEW, TEST, PLAN, DEVOPS, REFACTOR, FRONTEND, EXTEND, CODE
   - Injects 4-step mandatory pipeline into context

4. **Mandatory Pipeline** — problem-architect ALWAYS runs first
   - Step 1: problem-architect (BLOCKING — no coding until Team Spec returns)
   - Step 1b: Web research (MANDATORY)
   - Step 2: Load skills based on intent
   - Step 3: Specialist agents
   - Step 4: code-reviewer + test-writer (MANDATORY after implementation)
   - Removed all "skip if small task" escape hatches

5. **Self-Healing** — creates missing skills/agents on the fly
   - problem-architect flags MISSING skills in Team Spec
   - Hook instructs Claude Code to use skill-creator/agent-creator
   - Created skills persist for all future tasks

6. **Web Research** — mandatory for problem-architect, skill-creator, agent-creator
   - problem-architect now has WebSearch + WebFetch tools
   - Step 2b: "Web Research (MANDATORY for unfamiliar technologies)"
   - skill-creator + agent-creator: search best practices before writing
   - Brain Router Step 1b: "training data is frozen — search before coding"
